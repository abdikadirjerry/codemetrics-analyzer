# CodeMetrics 📊

CodeMetrics is a command-line static code analysis tool written in Python. It scans Python project directories to calculate metrics such as Lines of Code (LOC), function counts, class counts, and basic complexity estimates.

## Features
- Recursive directory traversal for Python source files.
- AST-based parsing for accurate code metrics without executing untrusted code.
- Clean summary reports generated directly in the terminal.

## Requirements
- Python 3.10+
- Ubuntu / Linux (WSL compatible)
